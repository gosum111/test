# เว็บไซต์สวนสมุนไพรสมเด็จพระเทพรัตนราชสุดาฯ สยามบรมราชกุมารี

เว็บไซต์ + ระบบจัดการหลังบ้าน (แอดมิน) ของสวนสมุนไพร
ใช้ **Python อย่างเดียว** ไม่ต้องติดตั้งโปรแกรมหรือไลบรารีเพิ่ม (Python 3.10 ขึ้นไป)

## เริ่มใช้งาน

| ทำอะไร | วิธี |
|---|---|
| เปิดเว็บ | ดับเบิลคลิก `start-server.bat` → เว็บ: http://localhost:8000 · แอดมิน: http://localhost:8000/admin.html |
| เปิดให้มือถือสแกนได้ | ดับเบิลคลิก `start-mobile.bat` → ได้ลิงก์ชั่วคราว + QR บนจอ + ตั้งเป็นที่อยู่ของป้าย QR ให้อัตโนมัติ (ต้องติดตั้ง cloudflared: `winget install --id Cloudflare.cloudflared`) |
| ทดสอบทั้งระบบ | ดับเบิลคลิก `tests\run-tests.bat` (ใช้สำเนาข้อมูล ไม่แตะข้อมูลจริง) |
| เปลี่ยนรหัสแอดมิน | `python server/server.py --set-password` |
| นำขึ้นออนไลน์ | ดู [DEPLOY.md](DEPLOY.md) |

## โหมดเว็บไซต์ทดลอง (เปิดอยู่เป็นค่าเริ่มต้น)

เว็บนี้เป็น**ต้นแบบเพื่อการศึกษา** จึงเปิดโหมดทดลองไว้:
- แถบสีเหลือง "เว็บไซต์ทดลอง — ไม่ใช่เว็บไซต์ทางการ" บนสุดของทุกหน้า
- ฟอร์มติดต่อแจ้งว่าข้อความไม่ถึงเจ้าหน้าที่จริง
- ห้ามเครื่องมือค้นหาเก็บเว็บ (`robots.txt` = Disallow ทุกหน้า + `noindex`)

ถ้าจะใช้เป็นเว็บจริง (ได้รับอนุญาตจากสวน/ปตท. แล้ว): เปิดเซิร์ฟเวอร์ด้วย `DEMO_MODE=0`
(PowerShell: `$env:DEMO_MODE="0"; python server/server.py` · บนเซิร์ฟเวอร์จริงตั้งไว้แล้วใน `deploy/herbgarden.service`)

## ป้าย QR ติดต้นไม้

แอดมิน → แท็บสมุนไพร → **🏷 พิมพ์ป้าย QR** → ใส่ที่อยู่เว็บจริง → เลือกพืช/ขนาด → พิมพ์
- QR ชี้ไปที่ `https://<เว็บ>/herb/plant/<เลขประจำพืช>` — สแกนแล้วเห็นรูปและข้อมูลของพืชชนิดนั้นทันที
- **เลขประจำพืชไม่เปลี่ยน** แม้แก้ข้อมูลหรือนำเข้าไฟล์ใหม่ (ชนิดที่ชื่อเดิมคงเลขเดิม) → ไม่ต้องพิมพ์ป้ายใหม่
- ถ้าลบพืชที่มีป้ายติดอยู่ ผู้สแกนจะเห็นข้อความแนะนำให้ไปหน้าค้นหา (กู้คืนจากถังขยะได้ เลขเดิมกลับมาใช้ได้)
- ต้อง**นำเว็บขึ้นออนไลน์ก่อน**พิมพ์ป้ายจริง (ที่อยู่ localhost ใช้กับมือถือผู้เข้าชมไม่ได้)
- ไลบรารีสร้าง QR: `js/vendor/qrcode.min.js` (qrcode-generator 1.4.4, MIT)

## โครงสร้างโปรเจกต์

```
index.html, css/, js/        หน้าเว็บ (HTML + CSS + JavaScript ล้วน ไม่ใช้ framework)
  js/main.js                 ตัวเปลี่ยนหน้า (ลิงก์จริง /news/3) และหน้าทั่วไป
  js/api.js                  ดึงข้อมูลจากเซิร์ฟเวอร์มาแสดง
  js/data.js                 ข้อมูลสำรอง (ใช้เมื่อเปิดไฟล์ตรง ๆ โดยไม่มีเซิร์ฟเวอร์) + ฟังก์ชันกลาง
  js/herb-search.js          หน้าค้นหาสมุนไพร
  js/activities.js           หน้ากิจกรรม + ปฏิทิน
  js/garden-map.js           แผนผังสวน (ข้อมูลกลุ่มแปลงอยู่ในไฟล์นี้)
admin.html, js/admin.js      หน้าแอดมิน
images/                      รูปภาพ (uploads/ = รูปที่อัปโหลดผ่านแอดมิน, plants/ = รูปพืช)
server/server.py             เซิร์ฟเวอร์ + REST API + ฐานข้อมูล
server/herbgarden.db         ★ ข้อมูลทั้งหมด (SQLite)
server/backups/              ไฟล์สำรองอัตโนมัติ
server/logs/server.log       บันทึกการทำงาน/ข้อผิดพลาด
server/admin.json            รหัสแอดมิน (เก็บเป็นค่าแฮช) — ห้ามแชร์
server/notify.json           ตั้งค่าแจ้งเตือน (มีรหัสอีเมล/LINE) — ห้ามแชร์
tests/                       ชุดทดสอบอัตโนมัติ
deploy/, DEPLOY.md           ไฟล์และคู่มือนำขึ้นออนไลน์
ขอข้อมูลจากสวน/               แบบฟอร์มขอข้อมูลจากเจ้าหน้าที่สวน
```

ไฟล์ในโฟลเดอร์ `server/`, `tests/`, `deploy/` และไฟล์ที่ไม่ใช่หน้าเว็บ (.txt .bat .md .csv ...) **เปิดผ่านเว็บไม่ได้**

## ระบบป้องกันข้อมูลหาย / ระบบล่ม

- **ถังขยะ** — ลบแล้วกู้คืนได้ภายใน 30 วัน (แท็บ 🗑 ถังขยะ)
- **สำรองอัตโนมัติ** — วันละครั้ง + ก่อนนำเข้าไฟล์ + ก่อนกู้คืน เก็บประเภทละ 30 ชุด (แท็บ 💾 สำรองข้อมูล)
- **ตรวจไฟล์ฐานข้อมูล** ทุกครั้งที่เปิดเซิร์ฟเวอร์และทุกวัน — ถ้าผิดปกติจะเตือนในแท็บ ✅ ความพร้อมของเว็บ
- **ฐานข้อมูลโหมด WAL** — อ่าน/เขียนพร้อมกันได้ ทนต่อไฟดับระหว่างบันทึก
- **เปิดใหม่อัตโนมัติ** — `start-server.bat` เปิดเซิร์ฟเวอร์ใหม่ให้เองถ้าหยุดทำงาน
- **ตรวจสุขภาพ** — `GET /api/health` (ใช้กับบริการเฝ้าดูเว็บ เช่น UptimeRobot) ตอบ 503 ถ้าฐานข้อมูลมีปัญหา
- **บันทึกข้อผิดพลาด** — `server/logs/server.log` (หมุนไฟล์ละ 1MB เก็บ 5 ไฟล์)

> สำรองข้อมูลนอกเครื่อง: ดาวน์โหลดไฟล์สำรองจากแท็บ 💾 และก๊อปโฟลเดอร์ `images/uploads/`, `images/plants/` เก็บไว้ที่อื่นอย่างน้อยเดือนละครั้ง

## ความปลอดภัย

- รหัสแอดมินเก็บเป็นค่าแฮช (PBKDF2) · ใส่ผิด 5 ครั้งใน 15 นาที → ล็อก 15 นาที
- การเข้าสู่ระบบเก็บเป็นค่าแฮชในฐานข้อมูล · หมดอายุเมื่อไม่ใช้งาน 12 ชม. (หรือ 30 วันถ้าติ๊ก "จดจำฉัน")
- ฟอร์มติดต่อ: กับดักบอต + จำกัดจำนวนต่อเครื่อง + กันข้อความซ้ำ/ลิงก์สแปม
- เปลี่ยนรหัสแอดมิน → ทุกคนถูกออกจากระบบทันที

## เมื่อเกิดปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| เปิดเว็บไม่ได้ | ดูหน้าต่าง `start-server.bat` ว่ามีข้อความผิดพลาดไหม · พอร์ต 8000 ถูกใช้อยู่ = เปิดเซิร์ฟเวอร์ซ้อนกัน ให้ปิดหน้าต่างเก่า |
| แอดมินเข้าไม่ได้ / โดนล็อก | รอ 15 นาที หรือปิด-เปิดเซิร์ฟเวอร์ใหม่ · ลืมรหัส → `python server/server.py --set-password` |
| ข้อมูลหาย / ผิดพลาด | แท็บ 🗑 ถังขยะ → กู้คืน หรือแท็บ 💾 สำรองข้อมูล → กู้คืนชุดที่ต้องการ |
| อยากรู้ว่าเกิดอะไรขึ้น | เปิด `server/logs/server.log` |
| แก้โค้ดแล้ว | รัน `tests\run-tests.bat` ให้ผ่านทั้งหมดก่อนนำขึ้นเว็บจริง |
